# PocketBank

Консольный учебный проект на C#. На основе https://github.com/Skyli120x60/bank.

Вместо фиксированного примера добавлено интерактивное меню: имя пользователя, пополнение, снятие и просмотр истории текущего сеанса. Есть проверка формата суммы, минимальной суммы и доступного остатка. Точка и запятая поддерживаются как десятичный разделитель.

## Запуск

Нужен .NET 10 SDK. Откройте bank.slnx в совместимой Visual Studio либо выполните из этой папки:

```
dotnet run --project bank/bank.csproj -c Release
```

Проверка: dotnet test bank.slnx -c Release

Баланс и история хранятся только до закрытия программы. Денежная модель исходного примера использует double; проект предназначен для обучения.

## Исходный проект

Исходная модель BankAccount и тесты сохранены. У исходного репозитория на момент скачивания не была указана лицензия; новая лицензия на чужой код не добавлена. Содержание PDF-записки сохранено; ФИО на титульном листе и в начале отчёта исправлено на «Вахрушев Кирилл Дмитриевич».
